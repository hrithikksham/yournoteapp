**Yournote** is a privacy-first, distraction-free **notes, journal, and reminder app** built for Android.  
Designed to feel fast, personal, and secure—without bloated features.

</div>

---

## ✨ Core Philosophy

> **Fast. Private. Owned by the user.**  
> No clutter. No dark UX patterns. No unnecessary cloud dependency.

Yournote is built as a **personal knowledge vault**, not a social product.

---

## 🏠 Home Experience

- Smooth **scrollable UI** with subtle animations  
- **Journal Book** & **Password Vault** protected by a changeable passcode  
- Dynamic **Reminders widget** with real-time date updates  
- User-defined **Labels** (Work, Ideas, Personal, etc.)  
- Notes rendered with **varying transparency** for visual clarity  
- **Offline-first** access  
- Always returns to **Home** when navigating back  

---

## 📝 Notes & Journaling

- Long-form notes (up to **20,000 words**)  
- Custom labels per note  
- Individual note locking using vault password  
- Clean, distraction-free editor  
- Offline creation with later sync  

---

## ⏰ Reminders

- Daily to-do lists  
- Auto-sorted by time & priority  
- Time-based and **location-based reminders**  
- Integrated with Android system services  

---

## 🔐 Security & Privacy

![Secure](https://img.shields.io/badge/Security-First-0A0A0A?style=for-the-badge)

- Single passcode for **Journal Book & Password Vault**  
- Secure local storage using **Expo Secure Store**  
- JWT-based authentication  
- Password hashing with **bcrypt**  
- Sensitive data never stored in plaintext  

---

## 👤 Authentication Flow

- Custom user accounts  
- Login / Signup / Forgot Password  
- Email-based password recovery  
- Profile image upload (Android 12+)  
- Auto-redirect to Welcome screen if unauthenticated  

---

## ⚙️ Settings

- Change vault passcode  
- Light / Dark theme toggle  
- GitHub source code link  
- Dynamic app version fetched via API  
- About page linked to LinkedIn
